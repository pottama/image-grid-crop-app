# 画像グリッド分割・切り抜きツール

ブラウザ上で画像のアップロード、AI背景削除、グリッド分割、自由切り抜きを行い、偶数サイズに統一された画像を一括または個別にダウンロードできるWebアプリです。**クライアントサイド完結**のため、画像データはサーバーに送信されません。

## 技術スタック

- React 18 + TypeScript
- Vite
- Tailwind CSS
- @imgly/background-removal（AI背景削除）
- JSZip（一括ZIPダウンロード）

## 使い方

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開き、JPEG または PNG（最大10MB、200〜4096px）をドラッグ＆ドロップまたは選択して開始します。

## 主な機能

- **トップ画面**: ドラッグ＆ドロップまたはファイル選択。形式・容量・解像度のバリデーション
- **AI背景削除**: ブラウザ内で背景を透過PNGに変換
- **元に戻す**: 背景削除を1段階取り消し
- **グリッド分割**: 縦・横の分割数（最大10×10）と範囲を指定して等サイズ・偶数で分割。端数はグレー表示で切り捨て
- **切り抜き**: 2px単位スナップの矩形範囲で切り抜き。幅・高さは偶数に自動補正
- **プレビュー**: グリッド/リスト表示切替、一括ZIPダウンロード、個別保存・削除

## 出力仕様

- 幅・高さは常に**偶数**に統一
- 背景削除後または元がPNGの場合は PNG、それ以外は JPEG（透過なしの場合は白背景）

## 開発

- `npm run build` … 本番ビルド
- `npm run preview` … ビルド結果のプレビュー
