# 画像 グリッド・範囲指定 切り抜きツール

ブラウザ上で画像のアップロード、AI背景削除、グリッド切り抜き、範囲指定切り抜きを行い、偶数サイズに統一された画像を一括または個別にダウンロードできるWebアプリです。**クライアントサイド完結**のため、画像データはサーバーに送信されません。

## 技術スタック

- React 18 + TypeScript
- Vite
- Tailwind CSS
- @imgly/background-removal（AI背景削除）
- JSZip（一括ZIPダウンロード）

## 使い方

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開き、JPEG または PNG（最大10MB、200〜4096px）をドラッグ＆ドロップまたは選択して開始します。

## 主な機能

- **トップ画面**: ドラッグ＆ドロップまたはファイル選択。形式・容量・解像度のバリデーション
- **背景削除**: ブラウザ内で背景を透過PNGに変換
- **元に戻す**: 背景削除を1段階取り消し
- **拡大・フィット・縮小**: 画像の拡大・画面フィット・縮小
- **背景切り替え**: 画像背景の切り替え
- **グリッド切り抜き**: 縦・横の分割数（最大10×10）と範囲を指定して等サイズ・偶数で分割。端数はグレー表示で切り捨て
- **範囲指定切り抜き**: 2px単位スナップの矩形範囲で切り抜き。幅・高さは偶数に自動補正
- **プレビュー**: グリッド/リスト表示切替、一括ダウンロード（ZIP）、個別保存・削除
- **リサイズ**: 出力画像のリサイズ（幅・高さ）アスペクト比固定

## 出力仕様

- 幅・高さは常に**偶数**に統一
- 背景削除後または元がPNGの場合は PNG、それ以外は JPEG（透過なしの場合は白背景）

## 開発

- `npm run build` … 本番ビルド
- `npm run preview` … ビルド結果のプレビュー

## デプロイ

`npm run build` を実行すると `dist` ディレクトリに静的ファイルが生成されます。
生成されたファイルは、Vercel、Netlify、GitHub Pages、Amazon S3 などの静的ホスティングサービスにそのままデプロイ可能です。
